# Zomato Restaurant Performance Analysis 🍽️📊

## Overview
This project analyzes restaurant and customer performance data for **Zomato**, a multinational restaurant aggregator and food delivery platform.  
The goal is to identify **top-performing restaurants, high-revenue cuisines, and demand patterns across cities** using an interactive Tableau dashboard.
